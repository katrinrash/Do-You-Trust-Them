# Do You Trust Them?

It is a 3D FPP detective game with narrative elements, inspired by Papers, Please, where the player takes the role of an office worker tasked with identifying a fraudster within a limited time. The player explores the office environment, interacts with computers, documents, and objects, and collects clues to solve the mystery.

> **Status: Completed (03.2025 - 06.2025)**  
> **Platform: Windows PC**

## Used Technologies:
- Unity / C#
- GitLab / GitKraken
- Trello / Miro

## Development Process:
"Do You Trust Them?" was created as a university project during my first year of Game Development studies. The game was developed by a four-person team over the course of 4 months, with two programmers working on the project.

I was responsible for developing key gameplay systems that formed the foundation of the core gameplay loop, as well as gameplay flow, UI logic, and narrative-related mechanics. I also worked on connecting individual systems and features into a cohesive player experience.

## My Contributions:
- Designed and implemented the day system using event-driven and data-driven approaches with Scriptable Objects, responsible for:
  -  time progression,
  -  day transitions,
  -  triggering gameplay events and activities.

- Created a modular computer hacking mini-game and expanded the office computer system connected to the day cycle, designing the mini-game as a reusable and easily extensible module independent from the rest of the game logic.

- Fully designed and implemented the notebook system used for tracking clues and collected information.

- Implemented multiple endings and an achievement system based on player choices and story outcomes, using interfaces to create modular and easily extensible outcome logic.

- Developed:
  - main menu logic,
  - animated day transition screens,
  - a text notification system reacting to player actions.

- Worked on gameplay flow, UI integration, and overall game feel.

## What I Learned:

- Understanding scene flow and additive scene loading
- Creating event-driven systems
- Collaborating with another programmer on shared systems and architecture
- Improving code organization and project structure in larger Unity projects
